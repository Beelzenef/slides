Fragments

Agrupa elementos sin nodos extra en el DOM

Evita divs innecesarios:

function Example(): JSX.Element {
    return (
        <>
            <h1>Título</h1>
            <p>Contenido</p>
        </>
    );
}

✅ DOM limpio, CSS sin interferencias

Props con TypeScript

Datos inmutables entre componentes

Tipado seguro:

interface GreetingProps {
    name: string;
    age?: number; // Opcional con default
}

function Greeting({ name, age = 18 }: GreetingProps) {
    return (
        <div>
            <p>Hola, {name}!</p>
            <p>Tienes {age} años</p>
        </div>
    );
}

PropTypes vs TypeScript

❌ PropTypes (Obsoleto)

  • Runtime validation
  • Paquete separado
  • No autocompletado

✅ TypeScript (Moderno)

  • Compile-time validation
  • Integrado
  • Autocompletado + IntelliSense

Reglas de los Hooks

¡SIEMPRE seguir estas reglas!
  1. Solo en el nivel superior
    Nunca en loops, condiciones o funciones anidadas
  2. Solo en componentes React
    O en otros custom hooks
  3. Prefijo "use"
    Para custom hooks

useState

Estado local en componentes funcionales

Tipado explícito:

function Contador(): JSX.Element {
    const [contador, setContador] = useState<number>(0);

    return (
        <div>
            <p>Contador: {contador}</p>
            <button onClick={() => setContador(contador + 1)}>
                Incrementar
            </button>
        </div>
    );
}

useEffect - Control de ejecución

Array de dependencias es clave
  • Sin array: Cada render
  • Array vacío []: Solo al montar
  • Con deps [dep1, dep2]: Cuando cambian

⚠️ Cleanup function: Evita memory leaks

useEffect - Cleanup

Patrón con limpieza:

function Temporizador(): JSX.Element {
    const [segundos, setSegundos] = useState<number>(0);

    useEffect(() => {
        const interval = setInterval(() => {
            setSegundos(prev => prev + 1);
        }, 1000);

        // 🧹 Cleanup function
        return () => clearInterval(interval);
    }, []); // Solo al montar

    return <div>Segundos: {segundos}</div>;
}

useRef

Referencias sin re-renderizado

Acceso directo al DOM:

function InputFoco(): JSX.Element {
    const inputRef = useRef<HTMLInputElement>(null);

    const manejarClick = (): void => {
        inputRef.current?.focus(); // Optional chaining
    };

    return (
        <div>
            <input ref={inputRef} type="text" />
            <button onClick={manejarClick}>Focalizar</button>
        </div>
    );
}

useCallback

Memoriza funciones para optimización

Úsalo cuando:

  • Pasas funciones a componentes con <code>memo</code>
  • En dependencias de otros hooks
  • Funciones costosas de crear

NO lo uses: para funciones simples

useReducer vs useState

useReducer

  • Estado complejo
  • Múltiples sub-valores
  • Lógica estructurada
  • Acciones específicas

useState

  • Estado simple
  • Primitivos/arrays
  • Actualizaciones directas
  • Sin lógica compleja

useReducer - Patrón

Tipado fuerte con Union Types:

interface State {
    contador: number;
}

type Action = 
    | { type: "incrementar" }
    | { type: "decrementar" }
    | { type: "reset" };

function reducer(state: State, action: Action): State {
    switch (action.type) {
        case "incrementar":
            return { contador: state.contador + 1 };
        // ... más casos
    }
}

Error Boundaries

Captura errores en el árbol de componentes

Capturan:

  • Errores en render
  • Errores en lifecycle methods
  • Errores en constructores

NO capturan:

  • Event handlers
  • Código asíncrono
  • Server-side rendering

Error Boundaries Modernas

react-error-boundary (recomendado):

import { ErrorBoundary } from 'react-error-boundary';

function ErrorFallback({ error, resetErrorBoundary }) {
    return (
        <div role="alert">
            <h2>¡Algo salió mal!</h2>
            <pre>{error.message}</pre>
            <button onClick={resetErrorBoundary}>
                Intentar de nuevo
            </button>
        </div>
    );
}

Beneficios de TypeScript

  • 🔍 Detección temprana de errores
    En tiempo de compilación, no runtime
  • 🚀 Mejor experiencia de desarrollo
    Autocompletado, refactoring seguro
  • 📚 Documentación viviente
    Los tipos documentan el código
  • 🔧 Mantenimiento más fácil
    Cambios seguros en grandes proyectos

Mejores Prácticas

  • Tipado explícito: Define interfaces para props
  • Cleanup functions: Siempre en useEffect
  • Custom hooks: Para lógica reutilizable
  • Error boundaries: En niveles estratégicos
  • Memorización: Solo cuando sea necesario
  • Convenciones: Nombres descriptivos

Errores Comunes

  • ❌ Hooks en condiciones
    Rompe el orden de ejecución
  • ❌ Olvidar cleanup
    Memory leaks en timers/suscripciones
  • ❌ useCallback innecesario
    Overhead sin beneficio
  • ❌ Estado derivado
    Usar useMemo en lugar de useState
