Hablemos de state management

Los widgets son inmutables

Solo podemos operar con el state y ante cambios en el state, el widget se redibuja

El state fluye y cambia con el uso

Stateless

Widgets que no van a cambiar con la interacción de users

Stateful

Widgets que “cambiarán” (se redibujarán) con la interacción de users

¿Y qué es state management?

Porque todo el mundo lo menciona...

Flutter es declarative, y eso hace que los widgets reaccionen a los cambios del state

Gestionemos de forma eficiente y ordenada el cómo se reflejan los cambios en la UI de nuestra app a medida que operamos

Existen muchas opciones para hacer state management

Momento de backend

Las opciones más populares

Dart Frog

Framework backend en Dart, inspirado en ergonomia moderna

Dart Frog: routing y middleware

  • Routing file-based facil de navegar
  • Middleware por ruta para auth, logs y validaciones
  • Handlers tipados para respuestas HTTP claras
  • Ideal para APIs pequeñas y medianas con equipos Dart

Dart Frog: developer experience

  • Hot reload en desarrollo backend
  • Estructura simple para empezar rapido
  • CLI para generar boilerplate
  • Buen encaje en equipos que ya usan Flutter

Serverpod

Backend en Dart orientado a productividad full-stack

Serverpod: arquitectura y tipado

  • Generacion de codigo para cliente y servidor
  • Endpoints tipados y contratos consistentes
  • ORM integrado para acceso a datos
  • Migraciones de base de datos incluidas

Serverpod: operativa

  • Panel de insights para logs y consultas
  • Sistema de sesiones y autenticacion utilizable
  • Background jobs para tareas asincronas
  • Buena opcion cuando quieres stack Dart completo

¿Y si no quiero gestionar mi propio backend?

Backend as a Service (BaaS) para acelerar el desarrollo

Firebase

BaaS con gran ecosistema para iterar muy rapido

Firebase: features core

  • Authentication con varios proveedores
  • Cloud Firestore para datos en tiempo real
  • Cloud Functions para logica backend sin servidor dedicado
  • Cloud Storage para archivos y media

Firebase: producto y observabilidad

  • Crashlytics para diagnosticar fallos en produccion
  • Analytics para eventos y funnels
  • Remote Config para feature flags y experimentacion
  • FCM para push notifications multi plataforma

Supabase

BaaS sobre Postgres con enfoque SQL-first

Supabase: base de datos y auth

  • PostgreSQL gestionado con extensiones modernas
  • Auth integrado con JWT y social login
  • RLS para control granular de acceso por fila
  • SQL como base para modelos y consultas complejas

Supabase: realtime y edge

  • Realtime subscriptions sobre cambios en Postgres
  • Storage para contenido y ficheros de app
  • Edge Functions para logica cerca del usuario
  • Panel SQL y APIs auto generadas para acelerar entrega

Firebase

Supabase

Serverpod

  • Framework backend full-stack con stack Dart
  • Generacion de codigo y contratos tipados
  • ORM, migraciones y enfoque de proyecto completo
  • Encaja en equipos que quieren backend Dart robusto

Dart Frog

  • Framework minimalista para APIs en Dart
  • Routing por archivos y middleware simple
  • Menor friccion para servicios pequeños/medianos
  • Encaja en equipos que buscan simplicidad y rapidez
