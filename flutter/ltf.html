Hablemos de state management

Los widgets son inmutables

Solo podemos operar con el state y ante cambios en el state, el widget se redibuja

El state fluye y cambia con el uso

Stateless

Widgets que no van a cambiar con la interacción de users

Stateful

Widgets que “cambiarán” (se redibujarán) con la interacción de users

¿Y qué es state management?

Porque todo el mundo lo menciona...

Flutter es declarative, y eso hace que los widgets reaccionen a los cambios del state

Gestionemos de forma eficiente y ordenada el cómo se reflejan los cambios en la UI de nuestra app a medida que operamos

Existen muchas opciones para hacer state management
